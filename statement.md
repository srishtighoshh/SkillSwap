# SkillSwap - Problem Statement

## Project Title
SkillSwap - Peer-to-Peer Student Skill Exchange Platform

## Problem Statement
Students often have useful skills that they can teach to others, while simultaneously wanting to learn different skills from their peers. However, there is no simple platform specifically designed to connect students based on what they can teach and what they want to learn.

SkillSwap addresses this problem by providing a peer-to-peer skill exchange platform where students can list their skills, specify learning interests, discover compatible students, send exchange requests, schedule learning sessions, and provide ratings and feedback.

## Scope
The system focuses on student-to-student skill exchange. It manages student profiles, skills, skill preferences, matching, exchange requests, learning sessions, and feedback.

## Target Users
- College students
- Student mentors
- Student learners
- Platform administrators

## High-Level Features
1. User registration and authentication
2. Skill management
3. User skill mapping
4. Skill matching
5. Skill exchange requests
6. Learning session scheduling
7. Ratings and feedback
8. SQLite database storage

## Technology Used
- Java
- JDBC
- SQLite
- Maven
- Object-Oriented Programming

## Expected Outcome
The system provides a structured way for students to exchange knowledge with one another by connecting learners with students who can teach the required skills.
